## Projetos em destaque

### [logiroute-api](https://github.com/LuizArioza/logiroute-api)
Sistema de priorização e roteamento de entregas para um centro de distribuição: prioriza remessas PRIME/EXPRESS, valida a capacidade de carga dos motoristas e rastreia o ciclo de vida do pacote do recebimento à entrega.

### [clt-rag-assistant](https://github.com/LuizArioza/clt-rag-assistant)
Assistente que responde perguntas sobre a CLT citando os artigos correspondentes, usando RAG (Retrieval-Augmented Generation) com PostgreSQL + pgvector para busca semântica e modelos rodando localmente via Ollama. Frontend em React, ambiente todo containerizado com Docker Compose.

### [sentinelauth-api](https://github.com/LuizArioza/sentinelauth-api)
API de autenticação e autorização com Spring Security, JWT (access token + refresh token com rotação), controle de acesso por papéis (RBAC) e proteção contra brute-force. Documentação via Swagger/OpenAPI e pipeline de CI no GitHub Actions.
