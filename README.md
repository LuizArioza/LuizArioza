## Projetos em destaque

### [sentinelauth-api](https://github.com/LuizArioza/sentinelauth-api)
API de autenticacao e autorizacao com Spring Security, JWT (access token + refresh token com rotacao), controle de acesso por papeis (RBAC) e protecao contra brute-force. Documentacao via Swagger/OpenAPI e pipeline de CI no GitHub Actions.

### [clt-rag-assistant](https://github.com/LuizArioza/clt-rag-assistant)
Assistente que responde perguntas sobre a CLT citando os artigos correspondentes, usando RAG (Retrieval-Augmented Generation) com PostgreSQL + pgvector para busca semantica e modelos rodando localmente via Ollama. Frontend em React, ambiente todo containerizado com Docker Compose.

### [logiroute-api](https://github.com/LuizArioza/logiroute-api)
Sistema de priorizacao e roteamento de entregas para um centro de distribuicao: prioriza remessas PRIME/EXPRESS, valida capacidade de carga dos motoristas e rastreia o ciclo de vida do pacote do recebimento a entrega.
